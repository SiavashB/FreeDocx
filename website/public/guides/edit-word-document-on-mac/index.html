How to edit a Word document on Mac without Microsoft Word

Open a Word file in FreeDocx and save your changes directly to the same .docx. If you edit in Apple Pages, export a Word copy to share the edited file in Word format.

Edit a .docx with FreeDocx

Open Résumé.docx, change one bullet, and press ⌘S. That same file is ready to send back. You can do all three steps offline with a file on your Mac.

  1. Open the original Word file

    In FreeDocx, choose File → Open and select the .docx you want to edit.

    Optional backup

    Before editing, select the file in Finder and press Command-D to make a backup. Continue working in the original.

  2. Change the text

    In this fictional résumé, select “three” in the experience bullet and type “five.” Selecting just the word keeps the rest of the bullet intact.

  3. Save and check the result

    Choose File → Save to update the file you opened. Close and reopen Résumé.docx to check the revised bullet and page breaks. You can send that file back or take turns editing it with an AI assistant.

FreeDocx handles text, basic formatting, and simple lists. For tracked changes, complex tables, or a legacy .doc file, check the FreeDocx compatibility FAQ before you start.

Edit and export a Word file in Apple Pages

Pages opens a Word file as a Pages document. A regular save uses the Pages format. Export to Word to get a separate .docx with your edits.

  1. In Pages, choose File → Open and select your Word document.
  2. Make your changes. Click Share in the toolbar, then choose Export and Send → Word. You can also use File → Export To → Word from the menu bar.
  3. Save the .docx copy, then reopen it to check the layout before sharing it.

For more on saving and sharing the Word copy, see Apple’s export instructions.
